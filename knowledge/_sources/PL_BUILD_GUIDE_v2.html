PL-BUILD-2025-002 // REV.2 PARADISE LOBBY — BUILD GUIDE FRONT TO BACK / ONE COMPLETE CASE
What this document is
Open this every time you build a case. It covers the complete production of one CUSTODY document and one DIRECTIVE document — blank canvas to Instagram post. Keep it open alongside Photoshop. When you lose your way, start from the top of whatever section you are in and work forward.
What one case produces
CUSTODYInternal record. Template C1, C2, or C3. No hero word. Dense form logic. Built first. Always.
DIRECTIVEOutward classification. Template D1, D2, or D3. Hero word at 144px+. Built second. Always.
Per document4 Instagram slides: full document + 3 detail crops
Total per case8 slides across 2 posts, minimum 4 hours apart
Build time45 minutes following the daily execution order on this page
Six elements — every document contains all six
1. Form structureHeader, field labels, field values, rule lines. Built first in 01_FORM_GRID1. This group never moves.
2. Hero wordDIRECTIVE only. One word from the 12-word lexicon at 144px+. Never in CUSTODY.
3. ExhibitDesaturated industrial image. 1px INK border, OCR tag, redaction bar. Lives in 02_CONTENT_GRID2.
4. StampOne primary stamp. The institution's last administrative action on this case.
5. Barcode + OCRCase data encoded. Machine-readable strings at document edges and footer.
6. DamageOne signature. Implies where the document sits in the institutional chain.
Kill-switch — apply continuously during building
After placing any element: does this explain what happened or why? If yes — delete it. Replace with [REDACTED] or PENDING. One explanatory sentence collapses System C into System B. No exceptions.
Five colours — these are materials, not a palette
#E2D9C8 — PAPER   #1C1914 — INK   #5B6B8A — STAMP BLUE
#B8B0A4 — SCAN GREY   #F0EBE1 — VOID WHITE
No other colours. No red. No orange. No pure RGB black (#000000). No exceptions.

PL-BUILD-2025-002 // REV.2 MASTER PSD SETUP — DO ONCE, NEVER REPEAT PL_GUIDES_MASTER_IG_v1.PSD
This page covers the one-time setup of your master file. Once built, this process never repeats. Every session starts by duplicating this file — you never work in the master directly.
SETUP A
Canvas + Base Layer
S.01
File → New. Width: 1080px. Height: 1350px. Resolution: 72. Color Mode: RGB 8-bit. Background: Transparent.
☐
S.02
Create a new layer at the absolute bottom of the layer panel. Name it PAPER_BASE. Fill with #E2D9C8. This layer never moves, never changes, and is never placed inside any group. It is the floor of every document you will ever build.
☐
SETUP B
Grid 1 — Layout Guides for Snapping
Grid 1 guides are Photoshop cyan guide lines. They exist only for snapping content to position. They are invisible at export and are not drawn as layers.
S.03
View → New Guide Layout. Margins: 72px all sides. Columns: 6, Gutter: 16px. Rows: 12, Gutter: 16px. Click OK. Your layout and snapping grid is in place.
☐
SETUP C
GRID1_VISIBLE — The Gutter=0 Method
Drawing lines directly from Grid 1 guides creates doubled lines at every gutter — two guide edges per boundary. The fix: a temporary second guide layout with gutter=0, used only to draw boundary lines cleanly, then discarded.
S.04
View → New Guide Layout again. Same margins (72px). Columns: 6, Gutter: 0. Rows: 12, Gutter: 0. CRITICAL: uncheck "Clear Existing Guides" — your Grid 1 guides must stay. Click OK. You now have two overlapping guide sets: Grid 1 with gutters (snapping) and boundary-only guides (drawing).
☐
S.05
Create layer group: 00_GUIDES. Inside it, create layer: GRID1_VISIBLE. Set layer opacity 50%.
☐
S.06
Line Tool (U). Mode: Shape. Stroke: 1px. Color: #B8B0A4. Fill: none. View → Snap → Snap to Guides: ON. Draw lines snapping only to the boundary-only (gutter=0) guides. Count exactly: 7 vertical lines (6 columns = 7 boundaries left-to-right) and 13 horizontal lines (12 rows = 13 boundaries top-to-bottom). 20 lines total. No doubles at gutters.
☐
S.07
View → Clear Guides. Then View → New Guide Layout to recreate Grid 1 (margins 72, columns 6 gutter 16, rows 12 gutter 16). GRID1_VISIBLE layer survives. The boundary-only guides are gone. This is the only time you ever do this — the grid is now permanent.
☐
7 vertical: 6 columns need 7 boundary edges. 13 horizontal: 12 rows need 13 boundary edges. Column boundaries only — not gutter centerlines, not gutter edges.
SETUP D
Layer Group Structure — Universal Stack
S.08
Create all groups in order, top to bottom. Every template you build starts with this exact stack. If any group is missing before you start — add it first.
☐
05_EXPORT_GUIDES → toggle OFF at export / carousel crop rectangles live here permanently
04_COLOR_GRADE → fixed Curves adjustment layer / set once, never alter
03_DAMAGE → one damage signature only / never combined
02_CONTENT_GRID2 → THIS GROUP MOVES — nudged by Grid 2 offset every session as one unit contains: all type / stamps / barcodes / OCR strings / exhibit IMAGE_SO / exhibit border / exhibit tag / redaction bar / clerk artifact 01_FORM_GRID1 → NEVER MOVES — form skeleton stays locked to Grid 1 contains: rule lines / field separators / table borders / structural boxes only 00_GUIDES → GRID1_VISIBLE layer / toggle OFF at export
PAPER_BASE → solid fill #E2D9C8 / absolute bottom / never inside any group
S.09
Save as PL_GUIDES_MASTER_IG_v1.psd. This file is never worked in directly. Every session: Image → Duplicate → save with case name → work in duplicate. Master stays clean indefinitely.
☐
Why two groups instead of one
Form lines (01_FORM_GRID1) simulate the printed template — they are always in the exact same position. Content (02_CONTENT_GRID2) simulates the human who filled the form in — they never aligned perfectly. The offset between them is institutional realism, not design choice.

PL-BUILD-2025-002 // REV.2 IMAGE SELECTION + TREATMENT PREPARE BEFORE OPENING TEMPLATE
The image is selected and treated before you open any template file. Never during building. Five minutes maximum. If you cannot find a passing image in five minutes, pull from your image bank. Spending more than five minutes choosing an image is an aesthetic decision — it is not permitted during a session.
What works
Corridor / passage
Institutional corridor, overhead lighting, no people. Identifiable as a specific building type: medical, municipal, industrial. Shot straight-on. Not expressive. Works with: ENTRY, EXIT, GATEWAY, THRESHOLD.
Technical infrastructure
Electrical panels, server racks, junction boxes, cable trays. The density of technical detail makes it illegible at first glance. That illegibility reads as classified. Works with: SIGNAL, STATIC, BREACH.
Building facade
Photographed frontally, dead-on, overcast light. No signage. Concrete or brick. Could be a processing facility, admin annex, storage unit. Anonymous. Becher method. Works with any lexicon word.
Object on surface
A tool, device, or container photographed like evidence — not styled. No depth of field effects. Flat, straight-on, uninflected. Works with: EVIDENCE, WITNESS, PRESSURE.
What does not work
Landscapes. Golden hour. Portraits. Dramatic angles. Anything where the composition was a deliberate aesthetic choice. If it belongs in a photography portfolio — it does not belong here.
Image test — one question
Does this image function as evidence of something? Or does it function because it looks good? If only the second — find a different image. The viewer must feel the image was photographed for a reason they cannot determine. Not because it is beautiful. Because something happened there.
Treatment — exact steps
IMG.01
Open image. Image → Adjustments → Desaturate. Greyscale in RGB mode.
☐
IMG.02
Curves (Cmd+M). Top-right anchor: drag down 5–8px — pulls highlights toward paper tone so image and document exist in the same tonal world. Bottom-left anchor: drag up 3–5px — lifts shadows off pure black to match INK value. Small moves. The image should feel processed and flattened, not dramatically filtered.
☐
IMG.03
Export as TIFF: PL_25_0001_IMG_01.tif. Place Embed this into both C and D templates as a Smart Object. One treated source image per case — same source, different crop and redaction in each document.
☐
Image bank
Maintain folder PL_REFS/IMAGES with at least ten pre-selected images ready to use. When no image passes the test in five minutes — pull from here. Build the bank outside of session time, never during building. Add to it when you find good sources, not when you need them.
Illustrator note
Illustrator is for structural elements only if you prefer vector rule lines or form boxes. Any Illustrator elements must be placed into the Photoshop PSD as Smart Objects into the correct layer group (01_FORM_GRID1 for structural elements, 02_CONTENT_GRID2 for content). The layer group logic does not change.

PL-BUILD-2025-002 // REV.2 DAMAGE / KILL-SWITCH / CAROUSEL / EXPORT APPLIES TO BOTH C AND D DOCUMENTS
Damage — one signature per document, never combined
SIG_A
Thermal fade		Gradient map layer, Soft Light blend, irregular brush mask (not a linear gradient), 40–60% opacity. Highlights pull toward #E2D9C8. Implies: disposable output, receipt printer. The institution did not expect this document to last.
SIG_B
Generation loss		New blank layer in 03_DAMAGE. Filter → Noise → Add Noise. Gaussian, Monochromatic, 2–4%. Set to Soft Light blend, 20% opacity. Implies: copied and recopied, original is elsewhere. Use for your first three cases.
SIG_C
Physical single		High-res scan of fold crease or torn edge, placed as Smart Object, Multiply blend, masked to document boundary. Must read as something that happened to this document. When SIG_C is active, nothing else runs in 03_DAMAGE.
DMG.01
Apply your logged damage signature in 03_DAMAGE. On/off toggle test: difference must be perceptible but not dramatic. Dramatic → reduce opacity. Invisible → increase until just perceptible.
☐
DMG.02
Same damage signature on both C and D for the same case. Same institutional chain position.
☐

PL-BUILD-2025-002 // REV.2 CASE SCENARIOS + STANDING RULES INSPIRATION + PERMANENT REFERENCE
Six case scenarios — content direction
Access event
Image: security door or barrier, straight-on. Hero: ENTRY or GATEWAY. Stamp: DENIED — INSUFFICIENT DISCLOSURE. Field ACCESS LEVEL → blank. The institution could not determine authorisation level.
Infrastructure record
Image: wire panel, server rack, junction box. Hero: SIGNAL or STATIC. Stamp: MANUAL REVIEW REQUIRED. Field TRANSMISSION STATUS → blank. Institution received something it could not classify.
Perimeter breach
Image: fence, wall, concrete barrier. Hero: BREACH or THRESHOLD. Stamp: SEIZURE ORDER ACTIVE. C2 chain of custody table: four rows, two with blank recipients. Case escalated but nothing was resolved.
Evidence intake
Image: object on surface — tool, device, container. Hero: EVIDENCE or WITNESS. Three exhibit tags in C1 (EXHIBIT 01, 02, 03) but only the first image is present. The other two exhibits are referenced but absent.
Pressure reading
Image: gauge, meter, measurement instrument. Hero: PRESSURE or STATIC. Stamp: NO FURTHER ACTION with blank DATE field. Decision made, never timestamped. The institution closed the case without closing it.
Exit protocol
Image: corridor end, emergency exit, stairwell bottom. Hero: EXIT or LEAK. D2 format — no hero word, boxed directive instead: ACCESS TO THIS RECORD HAS BEEN SUSPENDED. No reason. No duration.
Standing rules — no exceptions
R.01 If it looks designed, remove one element. This supersedes every other rule.
R.02 CUSTODY before DIRECTIVE. Every session without exception.
R.03 One damage signature per document. Never combined.
R.04 One primary stamp per document. Two secondary maximum.
R.05 PARADISE in file strings only. Never as readable text anywhere in the document.
R.06 Minimum two blank fields per CUSTODY document.
R.07 OCR never larger than DIN_LABEL in the same layout.
R.08 Five colours only. No red. No orange. No pure RGB black (#000000).
R.09 Image must function as evidence. If only atmosphere — find another image.
R.10 Log every session before opening Photoshop.
R.11 One clerk artifact per CUSTODY document. Logged every session.
R.12 Kill-switch before every export. One explanatory line = System B. Remove it.
R.13 02_CONTENT_GRID2 is the only group that moves. 01_FORM_GRID1 never moves.
R.14 No artboards. One canvas. Carousel crops as layer rectangles in 05_EXPORT_GUIDES only.
