# PL CANON RULES

Status: Active v3.0  
Purpose: Define the strict non-negotiable rules for **Paradise Lobby canon only**.

---

## 1. Canon definition

Paradise Lobby is not the event.
It is not the myth.
It is not the campaign.
It is not the explanation.

Paradise Lobby canon is:
- the archive
- the intake surface
- the procedural residue
- the institutional reaction to what cannot be classified

If a piece feels like the event, it is no longer Paradise Lobby canon.  
If a piece feels like promotion, it is no longer Paradise Lobby canon.  
If a piece feels like a stylish interpretation of bureaucracy, it is no longer Paradise Lobby canon.

---

## 2. Core governing idea

The institution processes things it cannot resolve.
The work is the trace of that processing.

Canon does not provide:
- narrative closure
- emotional explanation
- mythic framing
- campaign clarity
- viewer guidance

Canon provides administrative residue.

---

## 3. Canon system

Paradise Lobby canon operates in **System C** only.

That means:
- no event announcement
- no reconstructable narrative
- no resolution
- no clear future promise
- no expressive explanation
- no symbolic overstatement
- no dramatic escalation for effect

The viewer must leave with more questions, not fewer.
Reconstruction must fail.

---

## 4. Layer law

### L1 — EVENT (optional)
Imported source material.
May appear as:
- portrait fragment
- object
- site fragment
- scene-derived image
- altered still from motion material
- merged scene evidence
- source image trace

### L2 — SYSTEM (mandatory)
Administrative logic.
Must include visible institutional behavior such as:
- forms
- codes
- classifications
- routing
- denial
- copy marks
- OCR
- machine strings
- field structure
- stamps
- evidence labeling

### L3 — BREACH (rare)
Human failure or accidental interference.
Examples:
- correction bars
- scratches
- folds
- tape
- typing mistakes
- handling marks
- print distortion
- rescan slippage

### Rule
L2 must dominate.
If L1 dominates, the piece drifts out of canon.
If L3 starts behaving like style, remove it.

---

## 5. Canon priority rule

When judging a piece, always ask in this order:

1. **Is the system visible?**
2. **Is the image behaving like evidence?**
3. **Is the residue believable?**
4. **Is anything here performing for the viewer?**

If step 4 is yes, the piece is drifting.
Canon does not perform.
Canon exists as discovered residue.

---

## 6. Text behavior

Text must feel:
- cold
- procedural
- partial
- boring but intimidating
- institutional
- indifferent

Allowed:
- status phrases
- withheld fragments
- unreadable legal blocks
- routing strings
- administrative categories
- copy marks
- field labels
- unresolved directives
- machine-readable identifiers

Forbidden:
- slogans
- poetry
- motivational language
- clever ambiguity
- expressive commentary
- narrative explanation
- myth-making language
- seductive copywriting
- concept statements inside the work

Rule:
Text should never feel written to impress.
It should feel issued, logged, routed, or left incomplete.

---

## 7. Kill-switch

If any line explains what happened or why, delete it.
Replace it with one of the following:
- `[REDACTED]`
- `PENDING`
- `[BLANK]`
- a blank field
- a routing substitute
- a status substitute

This rule overrides all aesthetic decisions.

If explanation remains, the piece fails.

---

## 8. Tone

Paradise Lobby should feel like:
- one page of many
- bureaucratically cold
- impersonal
- unresolved
- processed but incomplete
- discovered, not presented
- handled, routed, withheld, filed, suspended, or misdirected

Paradise Lobby should not feel like:
- campaign announcement
- art poster about bureaucracy
- polished editorial design
- aestheticized paperwork cosplay
- cinematic myth-making
- cool system graphics detached from institutional logic
- fashion-first severity
- AI spectacle pretending to be evidence

---

## 9. Document logic

Canonical outputs should generally read as:
- custody sheets
- intake documents
- chain-of-custody tables
- classification directives
- archive cards
- access suspension notices
- evidence labels
- machine-coded fragments
- filed prints
- damaged copies
- processed evidence surfaces
- print-derived document panels

Rule:
Even when the source is synthetic, built, composited, or scene-derived, the **logic of the surface** must remain documentary and procedural.

Canon is judged by behavior, not by software origin.

---

## 10. Canon surface principle

Paradise Lobby is document-first.

This means the surface must behave like:
- a filed object
- a processed sheet
- a routed print
- a handled directive
- an evidence-bearing surface
- an institutional remainder

This does **not** mean canon is limited to one literal format.
Canon may resolve as:
- physical print
- Photoshop master built for print
- digital document surface
- poster-like document surface
- directive sheet
- archive panel
- print-study variant

What matters is not whether it is posted, printed, animated, or photographed.
What matters is whether it behaves like institutional residue.

---

## 11. Typography roles

Typography must have function.

### Bureaucracy type
Administrative body / header logic.

### Machine type
OCR, receipt, barcode, coded footer, routing strings.
Must appear somewhere in every canonical piece.

### Directive type
Rare power.
Denial, access, warning, classification, hold status.
Use carefully.

### Rule
Typography is not there to show design cleverness.
Typography is not there to create poster attitude.
Typography is there to reinforce institutional behavior.

### Canon stack rule
Paradise Lobby canon follows the fixed canonical font logic defined in operations documents.
JetBrains Mono may exist elsewhere in the broader project, but it is not the primary Paradise Lobby canon voice.

---

## 12. Large type in canon

Large type is allowed only when it behaves as:
- classification
- command
- denial
- access status
- warning
- directive emphasis

It must not behave as:
- slogan
- expressive headline
- decorative trend element
- poetic interruption
- campaign hook

Good words:
- HOLD
- WITNESS
- EVIDENCE
- BREACH
- ENTRY
- EXIT
- STATIC
- VOID
- SUSPENDED

Rule:
If the large word is doing all the work, the page is too thin.
If covering the large word collapses the piece, the piece fails.

---

## 13. Image logic

Images must function as evidence.
They must not function primarily because they are beautiful.

Strong image sources:
- portrait fragments processed as subject material
- corridors
- facades
- aerial/site fragments
- wire panels
- objects on surfaces
- industrial details
- partial human traces
- scene-derived composites that still read as evidence
- AI-generated source imagery processed into institutional evidence behavior
- Photoshop-built scene merges that still read as filed material

Weak image sources:
- cinematic beauty shots
- expressive landscapes
- portfolio-style fashion images without system layer
- atmosphere with no evidence function
- stylized hero imagery with no administrative framing
- image-first spectacle where the system is only pasted on top

Rule:
The image must feel collected, submitted, extracted, routed, or filed.
Not admired.

---

## 14. Friction and proof

Clean digital perfection fails canon.
Every canonical piece must include believable process proof.

Allowed proof:
- print / scan / rescan behavior
- fold crease
- tape edge
- crop misregistration
- stamp inconsistency
- toner-like degradation
- scanner shadow
- correction bar
- physical wear
- believable handling trace
- motion blur that reads as copying, scanning, dragging, or transfer behavior
- print distortion
- resampled edge behavior

Rule:
Use only what reads as believable for that document's chain position.
Proof is not a texture-pack aesthetic.
Proof is evidence of passage.

If the proof looks added for mood, reduce or remove it.

---

## 15. Clerk artifact

Where appropriate, include one sign of human processing error.

Examples:
- mistyped field label corrected with a white bar
- wrong attachment number
- struck-through handler name
- duplicate entry
- wrong routing value
- overwritten classification

This is not decoration.
It is evidence that a human touched the system.

Rule:
One good clerk artifact is stronger than five stylish damage gestures.

---

## 16. Canonical piece vs public release

A canonical piece is a single resolved canonical surface.

Examples:
- one CUSTODY document
- one DIRECTIVE document
- one archive card
- one evidence label sheet
- one processed print surface
- one document-panel print study

A public release may sequence one or more canonical pieces inside:
- a carousel dossier
- a case study post
- a motion sequence
- a print series presentation
- an artifact post

Rule:
The public release container is not the same thing as the canonical piece.
This distinction preserves the "one system per piece" rule.

Canon must stay strict even when distribution becomes contemporary.

---

## 17. Canon public release rule

Canonically, a case may resolve into:
- one CUSTODY piece
- one DIRECTIVE piece
- one supporting processed print or evidence surface where justified

Publicly, a case may also yield:
- a dossier carousel
- a print-study sequence
- a case-study reel
- an artifact post
- a physical proof post

Rule:
The canonical integrity lives in the underlying case logic, not in the platform container.

---

## 18. Case identity

A canonical case should feel like it belongs to a larger institutional archive.

Signs of this include:
- case number
- copy count
- footer strings
- repeated form structure
- machine-readable elements
- partial consistency across cases
- same institution, different departments
- repeatable evidence behavior
- stable administrative voice

If a piece feels unique only because it looks visually novel, that is weak.
If it feels unique because it is another unresolved page from the same institution, that is correct.

---

## 19. Hard fail conditions

A piece fails canon if any of the following are true:
- L2 is weak or absent
- machine logic is missing
- text explains what happened
- image behaves only as atmosphere or beauty
- large type behaves like slogan or poster hook
- proof/friction is absent
- residue feels decorative rather than evidentiary
- the page feels complete instead of archival
- the piece reads as marketing, myth, or cool graphics first

Fail means:
Do not call it canon.
It may still become public content, client translation, R&D, or source material.
But it is not Paradise Lobby canon.

---

## 20. Anti-drift rules

- If it looks designed, remove one element.
- If it explains, delete the explanation.
- If the image functions only as atmosphere, replace it.
- If the page feels complete instead of archival, add unresolved structure.
- If the human presence turns editorial or fashion-first, process it harder.
- If the work becomes merely cool bureaucracy, strip it back.
- If the print or physical proof becomes decorative rather than evidentiary, reduce it.
- If the system looks pasted onto an image, rebuild the surface.

---

## 21. Canon test

Before a piece is accepted as Paradise Lobby canon, ask:

1. Is L2 clearly present and dominant?
2. Is machine logic visible?
3. Is the text cold and procedural?
4. Is friction/proof present?
5. Does the image function as evidence?
6. Does reconstruction fail?
7. Does it feel like residue, not event?
8. Would this still function without its most dramatic element?

If any major answer is no, the piece is not canon yet.
