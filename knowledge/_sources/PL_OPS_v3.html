System classification

CUSTODYThe institution records internally. Intake, chain, archive. Templates C1, C2, C3. No hero word. Dense form logic. Speaks to itself without understanding what it is recording.

PL-OPS-2025-003 // REV.3 DAMAGE / STAMPS / CLERK ARTIFACT COPY 1 OF 1
Damage signatures — one per document, never combined
Damage communicates where the document sits in the institutional chain. Select based on what that implies — not on what looks best.
SIG_A — THERMAL FADE
Gradient map layer, Soft Light blend, irregular brush mask (not linear gradient), 40–60% opacity. Highlights toward #E2D9C8. Implies: receipt printer, low-security, disposable. The institution didn't expect this document to last.
SIG_B — GENERATION LOSS
High-pass → Threshold → Multiply layer at 15–30% opacity. Digital method: Filter → Noise → Add Noise (Gaussian, Monochromatic, 2–4%) on Soft Light layer at 20%. Type edges roughen slightly. Implies: this has been copied repeatedly. The original is elsewhere.
SIG_C — PHYSICAL SINGLE
Find a high-res scan of a fold crease, tape strip, or torn edge (archival paper texture sources). Import as Smart Object, Multiply blend, masked to document boundary. Must read as something that happened to the document, not something added to it. When SIG_C is active, no other damage layer runs.
Damage test: on/off comparison. Difference must be perceptible but not dramatic. If dramatic — reduce opacity. If invisible — increase until just perceptible.

Clerk artifact — mandatory, every CUSTODY document
One clerk artifact per CUSTODY document. This is not damage aesthetic — it is evidence that a human processed this form and made an error that the institution did not fully correct. Log which artifact was used. Do not repeat consecutively.
Mis-typed fieldType a field label with a typo: CLASSIFCATION. Cover with a narrow VOID_WHITE bar. Type the correct version beside or below it. The correction shows the institution tried. The error shows the clerk was human.
Crossed-out valueA field value struck through (thin INK line over the text) and replaced: HANDLER: [strikethrough] P. VAAN → J. MARSH. The case changed hands. Someone updated the form manually.
Wrong referenceFooter says ATT-02 but the document is clearly ATT-01. Nobody corrected it. The institution filed an incorrectly referenced copy.
Double entryOne field has two values stacked — the first partially obscured by VOID_WHITE, the second written below it. The clerk filled it in twice.

Daily execution — 45 minutes per session
MIN 00–05
Log: case number, date, template pair, posting order, damage signature, Grid 2 offset pair. Open CUSTODY template.
MIN 05–10
Replace IMAGE_SO. Baseline treatment (desaturate + curves). Image test: evidence or atmosphere? If atmosphere — find another. 5 min maximum.
MIN 10–15
Set all OCR strings to current case number. Complete field content. Apply Grid 2 offset. Leave minimum two fields blank. Add clerk artifact.
MIN 15–20
Open DIRECTIVE. Replace IMAGE_SO. Set hero word. Set stamp. Set OCR strings. Apply same Grid 2 offset values.
MIN 20–28
Toggle damage signature on both. Same signature per case pair. Assess: information about institutional position, or just texture? If texture — reduce opacity. Add reality artifact to each document.
MIN 28–38
Run kill-switch: find any line that explains. Replace with [REDACTED] or PENDING. Run anchor test. ANCHOR 4: remove the element that exists for aesthetic reasons. Export all carousel slides. Toggle off 05_EXPORT_GUIDES and 00_GUIDES.
MIN 38–45
Log completion: element cut and why, session time. Post in decided order. Minimum 4 hours between posts.
