PL-TRN-2025-003 // REV.3 PHASE 1 — COLOUR / PHASE 2 — GRID DIGITAL-FIRST
P1
Colour Calibration
1 SESSION / ~45 MIN
1.01
New Photoshop file: 1080×1350px, RGB, 72dpi. Fill background with #E2D9C8. Add a rectangle #1C1914. Add a smaller rectangle #5B6B8A. Add a 1px rule #B8B0A4. Add a small block #F0EBE1. Export as JPG 85%. Look at it on your phone. Does #E2D9C8 read as aged paper or as a colour chip? It must read as paper. Save as PL_REF_COLOUR_v1.psd.
☐
1.02
Search for three reference images: a scanned government form, a receipt photo, and a photocopied document. Study paper tone and ink quality. Note what makes them read as documents rather than designed objects. Save to PL_REFS/DOCUMENTS.
☐
1.03
Search for five industrial source images: corridors, facades, wire panels, concrete stairs, utility structures. Nothing expressive. Save to PL_REFS/IMAGES. This is your image bank — do not use yet.
☐
1.04
Take one reference document image. Bring into Photoshop. Desaturate. Open Curves: pull top-right point down 5–8px, pull bottom-left up 3–5px. Export and compare to original. This is the baseline treatment. Practice until it takes under 2 minutes.
☐
Phase 1 checkpoint
Look at PL_REF_COLOUR_v1.psd on your phone. Does #E2D9C8 feel like paper? If it still feels like a colour swatch — spend five more minutes looking at scanned document references until the association shifts.
P2
Grid Construction
1 SESSION / ~30 MIN
2.01
New Photoshop file: 1080×1350px, RGB, 72dpi. Background: solid fill #E2D9C8 on layer PAPER_BASE. This is always the bottom-most layer. It never changes.
☐
2.02
View → New Guide Layout. Columns: 6. Rows: 12. Margins: 72px all sides. Gutter: 16px. Confirm. All guides placed automatically.
☐
2.03
Create layer group 00_GUIDES. Inside it, create sublayer GRID_VISIBLE. Line Tool (U), Shape mode, 1px stroke, #B8B0A4, 50% opacity, Snap to Guides ON. Draw one line along each guide. This layer toggles off at export — it is never in the final image.
☐
2.04
Create the six PSD layer groups above PAPER_BASE in order: 05_EXPORT_GUIDES / 04_COLOR_GRADE / 03_DAMAGE / 02_TYPE_ADMIN / 01_IMAGE / 00_GUIDES. All empty. Save as PL_GRID_MASTER_IG_v1.psd. This is the master base for all templates.

PL-TRN-2025-003 // REV.3 PHASE 3 — TYPOGRAPHY DIGITAL-FIRST
P3
Character Styles + Scale Test
2 SESSIONS / ~90 MIN
Session 3A — Build character styles
3.01
Open PL_GRID_MASTER_IG_v1.psd. In 02_TYPE_ADMIN, build one text layer for each of the six character styles: DIN_INCIDENT / DIN_HEADER / DIN_LABEL / DIN_BODY / OCR_LINE / OCR_MICRO. Apply the exact font, size, tracking, and case from PL_OPS Section Typography. Name each layer with the style name.
☐
3.02
Set DIN_INCIDENT at 144px: type BREACH, left-aligned to the 72px margin, tracking +5. Look at 100% zoom (Cmd+1). Does it read as an administrative classification label or as a poster headline? If poster — the tracking is too wide. Reduce toward 0 until it reads as a label. Do not reduce the size.
☐
3.03
Test OCR_LINE: type PLB-IN/25/0001 // ATT-01 // HASH:[REDACTED] in OCR-B at 12px, tracking +80, #5B6B8A, placed at bottom of canvas 30px from edge. Export JPG 85%. Check on phone — the text should be small but visible if you look for it. If it disappears completely — increase to 14px maximum.
☐
Session 3B — Lexicon test (abbreviated)
3.04
Build four test exports — one canvas each: GATEWAY / WITNESS / THRESHOLD / EVIDENCE. Each: the lexicon word at DIN_INCIDENT scale, left-aligned to margin, with OCR_LINE below it. Nothing else. Export all four as JPG.
☐
3.05
AirDrop to phone. Scroll through fast. Each word: does it read as a classification label or as a statement? Classification — correct. Statement — that word needs more surrounding form content (field labels, case reference visible, stamp) in the real template before it earns its size. Note which words need this treatment.
☐
3.06
On two of the exports: cover the hero word with your thumb. Is there still something there? The OCR string alone — does it feel like a document fragment or like nothing? If nothing — the hero word is doing all the work. In real templates, you will need more administrative content below and around it.
☐
Phase 3 checkpoint
Show two of the lexicon test exports to someone who does not know this project. Do not explain. Ask: what are you looking at? Correct answer: documents, records, something official. If they say posters or art — return to step 3.02 and reduce the designed quality of the typographic presentation.
Phase 3 deliverables
PL_GRID_MASTER_IG_v1.psd with all character style layers saved and named. Four lexicon test exports with notes on which words need more context. OCR_LINE tested and confirmed readable at phone scale.

P4

3 SESSIONS / ~2.5 HRS
CUSTODY before DIRECTIVE. Always. The institution files before it acts. Build all three C templates before opening a D template. C templates have no hero word. They are the institution speaking to itself.
C1 — Intake Sheet
4.01
Duplicate PL_GRID_MASTER_IG_v1.psd. File → Save As → STP_C1_v01.psd. Check: all six layer groups present before any content is placed. Log your Grid 2 offset pair for this session.
☐
4.02
In 02_TYPE_ADMIN: header block at top, left margin. DIN_HEADER: INTAKE DOCUMENT — CLASSIFICATION PENDING. Below it: a 1px INK rule. Then three fields — CASE NO. / DATE / CLASSIFICATION — each with a label in DIN_LABEL and the value blank. No fills. Paper is the background.
☐
4.03
Right-side column: six field labels maximum in DIN_LABEL. Fill two with placeholder values in DIN_BODY. Leave at least two blank — label and field line present, no value. The blank fields are not errors. They are evidence of the institution's incomprehension.
☐
4.04
In 01_IMAGE: grey rectangle placeholder as IMAGE_SO. Add 1px INK exhibit border, 4px inset. Add OCR_LINE below: EXHIBIT 01 // REF: PL-25-XXXX-C. Add one VOID_WHITE redaction bar over the top third of the placeholder. Nudge the entire 01_IMAGE group by your Grid 2 offset.
☐
4.05
Add one clerk artifact — mis-typed field label corrected with VOID_WHITE, or wrong footer reference, or a struck-through field value. This is mandatory on every C template. Log which artifact you used.
☐
4.06
In 02_TYPE_ADMIN: add barcode using Libre Barcode 128 — type PL250001C, colour #1C1914, half-canvas width. Add one primary stamp (RECEIVED — UNCLASSIFIED), ±3° rotation, Multiply, 90% opacity. Add OCR_LINE footer: PLB-IN/25/XXXX // ATT-01 // HASH:[REDACTED].
☐
4.07
In 05_EXPORT_GUIDES: draw three labelled crop rectangles for carousel slides 2, 3, 4. CROP_SLIDE2_HEADER (around header and stamp), CROP_SLIDE3_IMAGE (around exhibit), CROP_SLIDE4_MACHINE (around footer/barcode zone). These stay in the template permanently.
☐
4.08
Run kill-switch: read every line of content. Does any line explain what happened or why? If yes — replace with [REDACTED] or PENDING. Run anchor test from PL_OPS. Log results. ANCHOR 4: identify the aesthetic element and remove it.

PL-TRN-2025-003 // REV.3 PHASE 7 — DAMAGE + ONGOING DIGITAL-FIRST
P7
All Three Damage Signatures + Production Rhythm
3 SESSIONS + ONGOING
7.01
SIG_A — THERMAL FADE: Case PL-25-0002. Gradient map layer, Soft Light, irregular brush mask, 40–60% opacity. Compare on/off. Difference: perceptible but not dramatic. If dramatic — reduce. If invisible — increase to just perceptible.
☐
7.02
SIG_B — GENERATION LOSS: Case PL-25-0003. High-pass → Threshold → Multiply at 15–30%. Digital method: Noise filter on Soft Light layer at 20%. Does it read as photocopy degradation or as Photoshop filter? If filter — reduce opacity and add irregularity to layer mask edges.
☐
7.03
SIG_C — PHYSICAL SINGLE: Case PL-25-0004. Find a high-res scan of a fold crease or torn edge. Import as Smart Object, Multiply blend, mask to document boundary. Must read as something that happened to the document. If it reads as added — find a different texture or reduce opacity.
☐
7.04
From Phase 7 onward: vary signatures across consecutive cases. Never the same signature three sessions in a row. After five cases, your archive should contain all three damage types — implying multiple institutional chain positions.
☐
7.05
After five complete cases (10 posts): open Instagram. Does the world exist? Can a viewer seeing the grid begin to understand they are looking at an institution — without explanation? If no — return to Phase 6 and examine pairing logic and case number visibility.
