# Graphic Design — Extra Context

Status: Active v2.0  
Purpose: Clarify the active cross-project context for Stranger Than Paradise / Paradise Lobby and resolve current scope conflicts.

---

This project includes ongoing work for Stranger Than Paradise / Paradise Lobby.

Paradise Lobby is not the event itself.
It is the archive, intake surface, procedural residue, and institutional reaction to what cannot be classified.

---

## Core visual order

- archive first
- evidence second
- artifact third
- beauty only as a byproduct of containment
- friction must feel earned, not decorative
- system language should feel cold, procedural, partial, and administrative

---

## Active project interpretation

This is an ongoing design system, not a one-off page or one-off campaign.
Prefer small, controlled changes over broad redesigns.
Preserve the archive/evidence framing unless explicitly revised.

---

## Type direction — scoped clarification

### Paradise Lobby canon
Paradise Lobby canon follows the fixed canonical font logic defined in the canon / operations documents.
Do not replace that with JetBrains Mono.

### Broader STP / interface / web / auxiliary environments
JetBrains Mono may be used when appropriate for:
- website/interface work
- system notes
- non-canonical STP layouts
- auxiliary environments that are not strict Paradise Lobby canon

Rule:
Do not let a web/interface type direction silently overwrite the Paradise Lobby canon stack.

---

## Current visual tendencies

- avoid polished portfolio behavior
- avoid expressive or overly cinematic presentation when discussing Paradise Lobby canon
- interfaces should feel processed, routed, withheld, scanned, or classified
- one believable sign of damage / withholding / interruption per major section is preferred
- physical proof is part of the system, not an afterthought

---

## Physical output

Physical prints, scanned prints, print studies, textured rescans, folded proofs, and handled poster surfaces are fully aligned with the project direction.
Use them as evidence-bearing material, not as decorative mockup polish.
