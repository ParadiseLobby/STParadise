# PUBLIC CONTENT SYSTEM

Status: Active v2.0  
Purpose: Define the public-facing content logic for Instagram and related channels without collapsing Paradise Lobby canon into generic content behavior.

---

## 1. Purpose of public content

Public content exists to do five things:
1. grow audience naturally
2. build recognizable identity
3. prove commercial capability
4. strengthen portfolio density
5. generate inbound work

It does **not** exist merely to post finished visuals.
It exists to prove that one maker has one machine that can produce repeatable, hireable, memorable work.

---

## 2. Public hierarchy

Not every public post is canon.

### Layer A — Commissionable worlds
Spec or real client-ready work.
This is the main growth and conversion layer.

### Layer B — Process / proof
Shows how source material becomes finished output.
This builds trust.

### Layer C — Paradise Lobby canon
Strict world output.
Used as authority, not as the entire feed.

### Layer D — Artifact / print / edition layer
Physical proof, print studies, object logic, wall proofs, labels, inserts, edition fragments.
This is both credibility and future commerce.

### Recommended ratio
- 50% Commissionable Worlds
- 20% Process / Proof
- 15% Paradise Lobby Canon
- 15% Artifact / Print / Edition

Rule:
Public content should not read like four separate accounts.
It should still read like one maker applying one visual machine to different public functions.

---

## 3. Source classes

All content should begin with one of three source classes.

### SUBJECT
Portrait, body fragment, face crop, fashion-adjacent figure, witness-like image.

### SITE
Drone frame, corridor, street fragment, facade, infrastructure, environmental evidence.

### OBJECT
Tool, garment, tag, label, package, surface, artifact, physical insert.

Rule:
A viewer should be able to identify the source class within seconds.

---

## 4. Public unit

The public unit is **not** a single poster.
The public unit is a **dossier release**.

A dossier release may contain:
- source imagery
- processed stills
- typography frames
- document surfaces
- detail crops
- motion frames
- artifact/print proof

### Critical rule
A dossier release is a public distribution container.
It is **not** the same as a single canonical piece.
This preserves world logic while remaining native to current Instagram behavior.

---

## 5. Main post formats

### FORMAT 1 — Release World Dossier
Main commercial format.
Use for speculative or real hireable work.

### FORMAT 2 — Process to Proof
Use for credibility.
Show source -> design -> motion -> print/scan -> final output.

### FORMAT 3 — Paradise Lobby Case
Use for authority.
Keep stricter and colder.

### FORMAT 4 — Artifact / Print Study
Use for tactile proof and future products.
Includes:
- print fragments
- wall proofs
- sleeve/envelope shots
- rescans
- label/tag sets
- physical inserts

---

## 6. Master dossier grammar

### 7-frame standard carousel

**Frame 1 — Hook / main surface**  
Strongest front-facing image.
May be:
- a full document surface
- a poster/document hybrid
- a strong release-world poster
- a print study front frame

**Frame 2 — Source**  
Raw portrait, site image, object, AI still, environment seed, or scene fragment.

**Frame 3 — Typographic interruption**  
Large classification word, command, denial, access language, or hard typographic frame.

**Frame 4 — Exhibit / primary crop**  
Tight crop of image zone, face fragment, object detail, site anomaly, or main poster section.

**Frame 5 — Machine / detail layer**  
Barcode, OCR footer, routing string, micro data, edge logic, poster micro-structure.

**Frame 6 — Motion**  
Short video or animated slide showing processing, scan behavior, type movement, or activation.

**Frame 7 — Artifact / print / afterimage**  
Physical print, sleeve, label sheet, desk shot, wall shot, fold detail, scanner pass, or object proof.

### Minimum rule
Every public post must contain at least 4 of the following 6:
- document or poster surface
- source image
- large type interruption
- detail crop
- machine layer or micro-structure
- motion or artifact/print proof

---

## 7. Public content pillars

### Pillar 1 — Release World Cases
Spec or real client-ready visual systems.
This is the main engine of follows and future work.

### Pillar 2 — Source to System
How source material becomes a campaign / dossier / poster / motion world.
This proves real making ability beyond prompting.

### Pillar 3 — Paradise Lobby Cases
Strict archival or administrative residues.
This proves authority and discipline.

### Pillar 4 — Artifact / Print Studies
Printed surfaces, damaged proofs, scans, label systems, case inserts, wall/application shots.
This proves physicality and gives future product logic.

### Pillar 5 — Motion Posters / Animated Text Systems
Reels or motion slides that feel like campaign assets, not random edits.

---

## 8. Large typography in public content

Large typography is allowed publicly, but under controlled conditions.

### Allowed uses
- directive frame
- classification interruption
- denial / access / warning frame
- motion text frame
- poster detail crop
- case-study frame where the type behaves like authority or categorization

### Not allowed
- big type on every frame
- poetic or expressive text
- slogan behavior
- decorative trend typography with no system function

Large type must behave like power, category, command, classification, or structural pressure.

---

## 9. Video / motion rules

Motion should feel like:
- processing
- activation
- transfer
- classification
- scan behavior
- system interruption
- image becoming output
- poster becoming campaign material
- print becoming evidence

Motion should not feel like:
- lifestyle vlog
- tutorial overload
- over-edited trailer behavior
- generic cinematic montage
- software flex for its own sake

### Good motion actions
- OCR typing in
- stamp landing
- crop line sliding
- image inserting into frame
- barcode appearing and drifting
- paper passing under scanline
- giant word flicker / reveal
- motion blur implying duplication / transfer
- print sheet entering or leaving frame

---

## 10. Case studies are public assets

Case studies are not separate from content.
They are one of the strongest public forms.

A case study may combine:
- multiple source scenes
- modified stills
- motion blur interventions
- typographic overlays
- Photoshop-built print surfaces
- wall/application shots
- motion excerpts
- artifact details

Rule:
If the case study proves hireable capability and still feels like your machine, it belongs on the feed.

---

## 11. Print and physical proof

Physical output is a public advantage.
Use it.

Public print/physical proof may include:
- Photoshop print studies
- large-format poster proofs
- folded copies
- scanner passes
- tape/fiber detail
- wall tests
- stacked case sets
- edition fragments

Rule:
Do not present physical proof as mockup polish.
Present it as handled material.

---

## 12. Caption system

Captions must remain sparse and controlled.

### Use
- case number
- status phrase
- source class
- copy count
- routing phrase
- one-line project label
- one-line commercial frame when useful

### Avoid
- explaining lore
- long conceptual essays under every post
- apologetic creator language
- motivational filler

### Caption types

**Type A — Case label**  
`PL-26-0041-C`

**Type B — Status label**  
`HOLD — REVIEW PENDING`

**Type C — Commercial frame**  
`Spec release world. Motion, posters, print studies, and system assets.`

Use Type C when conversion matters.

---

## 13. Weekly rhythm

### Core weekly pattern
- 2 Release World / Commissionable posts
- 1 Process / Proof post
- 1 Canon or Artifact / Print post

### Example cadence
**Mon** — Release world dossier  
**Wed** — Process / source-to-system  
**Fri** — Release world dossier  
**Sun** — Paradise Lobby canon or print/artifact study

---

## 14. Publishability test

A post is publishable only if it answers at least one of these clearly:
1. Why would the right person follow this account?
2. Why would the right person hire this maker?
3. Why does this strengthen the authority of the overall visual system?

If it answers none of them, do not post it.

---

## 15. Performance lens

Evaluate public content on:
- saves
- shares
- follows generated
- profile visits
- inbound messages / inquiries
- repeat recognizability across posts

Do not evaluate only by likes.

---

## 16. Anti-drift rules

- Do not let every post become a Paradise Lobby document.
- Do not let every post become a generic AI montage.
- Do not let process content turn into tutorial identity.
- Do not publish isolated experiments with no audience function.
- Do not treat the feed like a random dump of mediums.
- Do not let print studies become gallery cosplay with no commercial read.

---

## 17. Working principle

Public content should feel like:

**one maker, one machine, multiple outputs.**

That machine can generate:
- release worlds
- poster systems
- motion posters
- dossier sequences
- print studies
- artifacts

That is what creates recognition, scale, and commercial memory.
