## Core rule

Not every public post is canon.
Public content exists to distribute, prove, and translate the system — not to be the system.

---

## Public hierarchy

### Layer A — Commissionable worlds
Spec or real client-ready work. Main growth and conversion layer.

### Layer B — Process / proof
Shows how source material becomes finished output. Builds trust.

### Layer C — Paradise Lobby canon
Strict world output. Used as authority, not as the entire feed.

### Layer D — Artifact / print / edition layer
Physical proof, print studies, object logic, wall proofs, labels, inserts, edition fragments. Credibility and future commerce.

### Recommended ratio
- 50% Commissionable Worlds (Layer A)
- 20% Process / Proof (Layer B)
- 15% Paradise Lobby Canon (Layer C)
- 15% Artifact / Print / Edition (Layer D)

Rule: Public content should not read like four separate accounts. It should read like one maker applying one visual machine to different public functions.

---

## Source classes

All content should begin with one of three source classes.

**SUBJECT** — Portrait, body fragment, face crop, fashion-adjacent figure, witness-like image.

**SITE** — Drone frame, corridor, street fragment, facade, infrastructure, environmental evidence.

**OBJECT** — Tool, garment, tag, label, package, surface, artifact, physical insert.

Rule: A viewer should be able to identify the source class within seconds.

---

## The public unit

The public unit is not a single poster.
The public unit is a **dossier release**.

A dossier release may contain: source imagery, processed stills, typography frames, document surfaces, detail crops, motion frames, artifact/print proof.

**Critical rule:** A dossier release is a public distribution container. It is not the same as a single canonical piece. This preserves world logic while remaining native to current Instagram behavior.

---

## Main post formats

**FORMAT 1 — Release World Dossier**
Main commercial format. Use for speculative or real hireable work.

**FORMAT 2 — Process to Proof**
Use for credibility. Show source → design → motion → print/scan → final output.

**FORMAT 3 — Paradise Lobby Case**
Use for authority. Keep stricter and colder.

**FORMAT 4 — Artifact / Print Study**
Use for tactile proof and future products.
Includes: print fragments, wall proofs, sleeve/envelope shots, rescans, label/tag sets, physical inserts.

## 7-frame dossier grammar

### Standard carousel structure

**Frame 1 — Hook / main surface**
Strongest front-facing image. May be: a full document surface, a poster/document hybrid, a strong release-world poster, a print study front frame.

**Frame 2 — Source**
Raw portrait, site image, object, AI still, environment seed, or scene fragment.

**Frame 3 — Typographic interruption**
Large classification word, command, denial, access language, or hard typographic frame.

**Frame 4 — Exhibit / primary crop**
Tight crop of image zone, face fragment, object detail, site anomaly, or main poster section.

**Frame 5 — Machine / detail layer**
Barcode, OCR footer, routing string, micro data, edge logic, poster micro-structure.

**Frame 6 — Motion**
Short video or animated slide showing processing, scan behavior, type movement, or activation.

**Frame 7 — Artifact / print / afterimage**
Physical print, sleeve, label sheet, desk shot, wall shot, fold detail, scanner pass, or object proof.

### Minimum rule
Every public post must contain at least 4 of the following 6:
- document or poster surface
- source image
- large type interruption
- detail crop
- machine layer or micro-structure
- motion or artifact/print proof

## Large typography in public content

Large typography is allowed publicly, but under controlled conditions.

**Allowed:** directive frame, classification interruption, denial/access/warning frame, motion text frame, poster detail crop, case-study frame where the type behaves like authority or categorization.

**Not allowed:** big type on every frame, poetic or expressive text, slogan behavior, decorative trend typography with no system function.

Rule: Large type must behave like power, category, command, classification, or structural pressure.

---

## Motion rules

Motion should feel like: processing, activation, transfer, classification, scan behavior, system interruption, image becoming output, poster becoming campaign material, print becoming evidence.

Motion should not feel like: lifestyle vlog, tutorial overload, over-edited trailer behavior, generic cinematic montage, software flex for its own sake.

**Good motion actions:** OCR typing in, stamp landing, crop line sliding, image inserting into frame, barcode appearing and drifting, paper passing under scanline, giant word flicker/reveal, motion blur implying duplication/transfer, print sheet entering or leaving frame.

---

## Print and physical proof

Physical output is a public advantage. Use it.

Public print/physical proof may include: Photoshop print studies, large-format poster proofs, folded copies, scanner passes, tape/fiber detail, wall tests, stacked case sets, edition fragments.

Rule: Do not present physical proof as mockup polish. Present it as handled material.

---

## Caption system

Captions must remain sparse and controlled.

**Use:** case number, status phrase, source class, copy count, routing phrase, one-line project label, one-line commercial frame when useful.

**Avoid:** explaining lore, long conceptual essays under every post, apologetic creator language, motivational filler.

**Caption types:**

- Type A — Case label: `PL-26-0041-C`
- Type B — Status label: `HOLD — REVIEW PENDING`
- Type C — Commercial frame: `Spec release world. Motion, posters, print studies, and system assets.`

Use Type C when conversion matters.

## Publishability test

A post is publishable only if it answers at least one of these clearly:
1. Why would the right person follow this account?
2. Why would the right person hire this maker?
3. Why does this strengthen the authority of the overall visual system?

If it answers none of them, do not post it.

---

## Anti-drift rules (public content)

- Do not let every post become a Paradise Lobby document.
- Do not let every post become a generic AI montage.
- Do not let process content turn into tutorial identity.
- Do not publish isolated experiments with no audience function.
- Do not treat the feed like a random dump of mediums.
- Do not let print studies become gallery cosplay with no commercial read.

---

## Working principle

Public content should feel like: **one maker, one machine, multiple outputs.**

That machine can generate: release worlds, poster systems, motion posters, dossier sequences, print studies, artifacts.

That is what creates recognition, scale, and commercial memory.

## Commercial bridge — client translation

### Core rule
Paradise Lobby is the strictest laboratory.
Client work is the translated application.

The goal is not to make every client look like a Paradise Lobby government file.
The goal is to translate the strongest parts of the system into usable, sellable, memorable visual outputs.

### What always carries over

These qualities should remain visible in most client work:
- atmosphere with control
- system logic
- typographic pressure
- sequence thinking
- tactile proof / friction
- archive/evidence sensibility
- confidence in cropping and withholding
- image-to-world transformation
- print awareness
- motion-to-still continuity

### What does NOT need to carry over literally

Do not force these onto all client work:
- case numbering everywhere
- OCR and barcodes in every project
- administrative residue as literal surface language
- full Paradise Lobby legal / intake behavior
- canon-only wording
- full no-explanation doctrine in every commissioned piece

Those belong to the lab, not automatically to all deliverables.

---

## Translation levels

### Level 1 — Surface translation
Use selected aesthetic features only: texture, type logic, damage/folds, restraint, evidence-like image handling, print/scan materiality.
Best for: fashion, editorial, product campaigns.

### Level 2 — Structural translation
Use system logic in layout and rollout: paired assets, document-like sequencing, classification language, progressive reveal, release as dossier, case-study carousel structure.
Best for: music releases, exhibitions, identity systems.

### Level 3 — Deep translation
Use near-canonical pressure where appropriate: withheld information, filing logic, artifact drops, directive language, administrative pressure, stronger evidence behavior.
Best for: art projects, cultural institutions, experimental campaigns, self-initiated work.

---

## Best-fit client categories

**Strongest fit:** musicians and labels, underground or culture-led fashion brands, exhibitions/curators/screenings, editorial/publishing projects, art direction-heavy launches.

**Medium fit:** product-based brands seeking a harder image language, campaign launches needing a stronger world layer, cultural start-ups with concept-heavy identity.

**Weak fit:** generic corporate communication, soft wellness brands, purely friendly lifestyle branding, clients who need clean generic platform-native work only.

Rule: Do not bend the system to weak-fit clients just to say yes.

## Flagship release-world offer

### RELEASE WORLD SYSTEM

Possible deliverables:
- 1 visual direction
- 2–4 posters
- 1 motion poster / reel
- 4–8 rollout assets
- optional dossier/document application
- optional artifact/detail support
- optional print-study or edition proof

Why this leads: easy to understand, uses the full stack, naturally generates portfolio content, can be sold as both spec and client work, bridges AI source generation with real design discipline.

### Supporting offers
- Motion Poster Pack
- Print Study / Artifact Add-On
- Edition Development Add-On
- Dossier Rollout Add-On

## Client-facing language

**Good client-facing terms:** visual world, release system, campaign rollout, motion poster, poster series, print study, visual identity layer, art-directed rollout, tactile campaign assets, release-ready world.

**Terms to use carefully:** archive, evidence, dossier, directive, artifact.

**Terms to avoid as lead language:** Paradise Lobby, System C, residue, incomprehension, canon doctrine, administrative processing language as internal jargon.

Reason: Clients buy outcomes, not internal mythology.

---

## How to pitch

**Do not say:**
- I make weird experimental government-file aesthetics
- I build fictional bureaucratic worlds
- I do AI art plus graphic design plus motion plus whatever you need

**Say:**
- I build release-ready visual worlds across posters, motion, print studies, and campaign assets
- I can turn a concept or source image into a complete rollout language
- My work combines AI image generation with strong graphic finishing, sequence logic, and physical proof

---

## Anti-drift rules (commercial)

- Do not force Paradise Lobby skin onto every project.
- Do not erase your differentiators to satisfy generic briefs.
- Do not speak to clients in internal world jargon.
- Do not reduce the system to trend aesthetics.
- Do not treat client work as fully separate from your authorship.
- Do not accept work that destroys your public positioning just to stay busy.
- Do not allow Paradise Lobby to swallow the whole commercial front-end.

---

## Core translation statement

**The client does not need the whole world. They need the strongest translated pressure of the world, shaped into a release-ready outcome.**

That is the correct balance.
