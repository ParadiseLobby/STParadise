# Archive

Files in this folder are DEPRECATED. They are kept for historical 
reference and to preserve audit trail. Claude must not treat any 
file here as authoritative under any circumstance.

When moving a file here:
1. Add a DEPRECATED header to the top of the file with the date 
   and the version that replaces it
2. Update ACTIVE_MANIFEST.md to reflect the new active version
3. Log the change in PROJECT_LOG.md
